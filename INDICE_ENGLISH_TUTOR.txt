🛠️ SCRIPTS DE INSTALACIÓN
═══════════════════════════

⭐ setup_english_tutor_master.py
   Script MAESTRO que ejecuta todo el proceso de generación.
   
   Uso:
   python setup_english_tutor_master.py
   
   Hace:
   • Ejecuta setup_english_tutor_full.py (Parte 1)
   • Ejecuta setup_english_tutor_full_part2.py (Parte 2)
   • Muestra instrucciones finales


📦 setup_english_tutor_full.py
   Parte 1: Genera módulos core
   
   Crea:
   • pyproject.toml, .env.example, .gitignore, README.md
   • src/english_tutor/config.py
   • src/english_tutor/competencies/ (models.py, tracker.py)
   • src/english_tutor/exercises/ (types.py, generator.py)
   • src/english_tutor/database/ (storage.py)


📦 setup_english_tutor_full_part2.py
   Parte 2: Genera agente y UI
   
   Crea:
   • src/english_tutor/agent/ (state.py, tutor_agent.py)
   • src/english_tutor/models/ (stt.py, tts.py)
   • src/english_tutor/ui/ (app.py)
   • src/english_tutor/tutor.py
   • scripts/run_tutor.py


🔍 verify_english_tutor_setup.py
   Script de verificación
   
   Verifica:
   • Que todos los archivos de setup existan
   • Que la documentación esté presente
   • Versión de Python (3.11+)
   
   Uso:
   python verify_english_tutor_setup.py

📋 CHECKLIST DE INSTALACIÓN
════════════════════════════

□ 1. Verificar archivos
     python verify_english_tutor_setup.py

□ 2. Generar proyecto
     python setup_english_tutor_master.py

□ 3. Navegar al proyecto
     cd english_tutor

□ 4. Copiar configuración
     cp .env.example .env

□ 5. Editar .env
     - OLLAMA_MODEL=llama3.2
     - GROQ_API_KEY=tu_key (si usas Groq STT)
     - TTS_MODEL=kokoro
     - STT_MODEL=whisper-groq

□ 6. Instalar dependencias
     pip install -e .

□ 7. Verificar Ollama
     ollama serve
     ollama list

□ 8. Ejecutar tutor
     python scripts/run_tutor.py

□ 9. Abrir navegador
     http://localhost:7860

❓ PREGUNTAS FRECUENTES
═══════════════════════

Q: ¿Dónde empiezo?
A: Lee RESUMEN_ENGLISH_TUTOR.txt y ejecuta setup_english_tutor_master.py

Q: ¿Qué modelos Ollama debo usar?
A: llama3.2 (rápido) o qwen2.5 (mejor para enseñanza)

Q: ¿Necesito internet?
A: No, excepto si usas whisper-groq para STT (opcional)

Q: ¿Cómo cambio el modelo TTS?
A: Edita TTS_MODEL en .env (opciones: kokoro, together, edge)

Q: ¿El proyecto se mezcla con el padre?
A: No, está totalmente separado en english_tutor/

Q: ¿Cómo funciona la integración con el proyecto padre?
A: Importa modelos STT/TTS pero todo lo demás es independiente

Q: ¿Puedo tener múltiples estudiantes?
A: Sí, cambia DEFAULT_STUDENT_NAME en .env o usa la API

Q: ¿Dónde se guarda el progreso?
A: En data/students.db (SQLite)
